# Versioned Feature Specifications Repository (`specs/all/`)

This directory contains ALL versions of feature specifications across all lifecycle states (`DRAFT`, `APPROVED`, `BUILDING`, `DONE`, `DEPRECATED`).

## File Naming Convention
`<feature_number>-<feature_slug>-v<version>.md`

Examples:
- `01-line-of-inquiry-v1.md`
- `01-line-of-inquiry-v2.md`
- `02-branching-chat-v1.md`

## Header Schema
```yaml
---
feature_id: SPEC-01
title: Line-of-Inquiry Instructor Evaluation Dashboard
version: 1.0
status: DRAFT # DRAFT | APPROVED | BUILDING | DONE | DEPRECATED
last_updated: YYYY-MM-DD
---
```
